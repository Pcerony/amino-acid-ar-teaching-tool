# 氨基酸图鉴相机

面向日本小学 5–6 年级的手机端识别教具。学生将教具的一面对准圆形取景框，页面可识别完整的 20 种图案，把名称和分子模型固定到该面，并提供简短的日语学习卡。

## 当前范围

- 支持完整的 20 种标准氨基酸，包含疏水、极性、酸性、碱性和含硫等类别。
- 优先在浏览器本地完成颜色筛选、ORB 特征匹配和多帧确认。
- 颜色筛选使用每张参考图的实际 HSV 画像，常规只将最接近的 8 个目标交给 ORB；低置信度时以 700 毫秒冷却间隔进行一次全量复核，避免相似颜色图案被提前排除。几何评分会保留低内点时的灵敏度，同时给强 RANSAC 内点数小幅加权，避免颜色近邻压过真实图案。
- 识别后只追踪当前面，通过 RANSAC 单应矩阵让环形 AR 信息跟随位置、缩放、旋转和倾斜。
- 使用 PubChem 离线 3D conformer 构建准确的球棍分子模型；默认显示日文名称、缩写和缓慢自转的 3D 分子。
- 点击 AR 模型或底部入口后，展开完整学习内容。
- 本地持续不确定时，可选择性地把取景框内的一张压缩图片交给云端复核。
- 不录音，不上传连续视频，不保存学生的摄像头画面。

## 性能策略

- 寻找二十种图案时以约 250 毫秒的帧起始间隔分析，识别耗时不会再额外叠加到等待时间。
- 锁定后只匹配一个参考目标，正常约每 180 毫秒追踪一帧；持续计算变慢时降为约 250 毫秒。
- 身份匹配与平面姿态估计分开处理：短暂反光、倾斜或遮挡只冻结 AR 位置，不会立刻清除识别结果；连续 2.4 秒无法匹配后才回到全目标搜索。
- Three.js 在首次识别成功后才加载，动画限制为 20 帧/秒，渲染像素比最高为 `1.25`，不使用阴影和后期处理。
- 页面隐藏、目标丢失或学习卡片展开时暂停无用追踪或 3D 动画。
- WebGL 初始化失败时显示由同一分子数据生成的二维球棍投影。

## 本地运行

```bash
npm install
npm run dev
```

开发地址为终端显示的 Local URL。桌面浏览器可以使用“照片识别”验证参考图；真实摄像头流程应在 HTTPS 手机页面上验证。

## 可选云端复核

复制 `.env.example` 为本地环境文件并配置：

```bash
OPENAI_API_KEY=
OPENAI_VISION_MODEL=gpt-5.6-luna
```

未配置密钥时，云端接口返回 `503`，本地识别继续工作。生产环境的密钥必须保存在服务端环境变量中，不能写入浏览器代码或仓库。

## 验证命令

```bash
npm test
npm run lint
npx tsc --noEmit
npm run build:pages
```

需要重新获取分子数据时运行：

```bash
npm run molecules:generate
```

该命令访问 PubChem；正常运行和课堂使用不需要联网获取分子结构。

检查 20 张参考图是否都进入颜色候选集：

```bash
npm run recognition:audit
```

## 实机验收清单

### iPhone Safari

- HTTPS 页面能在点击按钮后请求摄像头权限。
- 使用后置摄像头，画面不拉伸。
- 圆形取景框在旋转屏幕前后保持正圆。
- 连续识别同一面三次后才切换教学卡。
- 锁定后，环形信息和分子模型随教具表面移动，不固定在屏幕中央。
- 转动教具时只显示最大、最清晰的一面，不同时出现多个 AR 层。
- 轻微遮挡不会让 AR 层立即跳走，持续丢失后会返回寻找状态。
- 收起和展开教学卡时，按钮与文字不重叠。
- 停止或离开页面后，系统摄像头指示立即消失。

### Android Chrome

- HTTPS 页面能在点击按钮后请求摄像头权限。
- 支持的设备只在摄像头能力可用时显示闪光灯按钮。
- 低光、反光和目标过小时显示相应的日语提示。
- 3D 分子自转流畅，摄像头预览没有明显卡顿。
- 手机底部手势区域不遮挡操作按钮。
- 停止或离开页面后，所有视频轨道都被关闭。

## 课堂校准建议

正式上课前，用实际打印纸张、教室灯光和计划使用的两类手机，各采集每一面至少 10 次识别结果。若某两面容易混淆，应优先补充实际拍摄参考图并重新调整阈值，不应通过降低置信度门槛来强行显示名称。
