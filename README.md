# 氨基酸图鉴相机

面向日本小学 5–6 年级的手机端识别教具。学生将正八面体的一面对准圆形取景框，页面会识别图案并显示简短的日语学习卡。

## 第一版范围

- 支持 8 种氨基酸：丙氨酸、缬氨酸、亮氨酸、异亮氨酸、甲硫氨酸、苯丙氨酸、色氨酸和脯氨酸。
- 优先在浏览器本地完成颜色筛选、ORB 特征匹配和多帧确认。
- 本地持续不确定时，可选择性地把取景框内的一张压缩图片交给云端复核。
- 不录音，不上传连续视频，不保存学生的摄像头画面。

## 本地运行

```bash
npm install
npm run dev
```

开发地址为终端显示的 Local URL。桌面浏览器可以使用“照片识别”验证参考图；真实摄像头流程应在 HTTPS 手机页面上验证。

## 可选云端复核

复制 `.env.example` 为本地环境文件并配置：

```bash
OPENAI_API_KEY=
OPENAI_VISION_MODEL=gpt-5.6-luna
```

未配置密钥时，云端接口返回 `503`，本地识别继续工作。生产环境的密钥必须保存在服务端环境变量中，不能写入浏览器代码或仓库。

## 实机验收清单

### iPhone Safari

- HTTPS 页面能在点击按钮后请求摄像头权限。
- 使用后置摄像头，画面不拉伸。
- 圆形取景框在旋转屏幕前后保持正圆。
- 连续识别同一面三次后才切换教学卡。
- 收起和展开教学卡时，按钮与文字不重叠。
- 停止或离开页面后，系统摄像头指示立即消失。

### Android Chrome

- HTTPS 页面能在点击按钮后请求摄像头权限。
- 支持的设备只在摄像头能力可用时显示闪光灯按钮。
- 低光、反光和目标过小时显示相应的日语提示。
- 手机底部手势区域不遮挡操作按钮。
- 停止或离开页面后，所有视频轨道都被关闭。

## 课堂校准建议

正式上课前，用实际打印纸张、教室灯光和计划使用的两类手机，各采集每一面至少 10 次识别结果。若某两面容易混淆，应优先补充实际拍摄参考图并重新调整阈值，不应通过降低置信度门槛来强行显示名称。
